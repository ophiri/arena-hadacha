# זירת ההדחה

משחק זירה סאטירי מקורי בעברית עם זרימת משחק מלאה: מסך ראשי, בחירת מצב,
בחירת דמויות, קרב, תוצאה ומשחק חוזר. אפשר לשחק לבד מול המחשב או בקרב מקומי
לשני שחקנים על מקלדת אחת.

[משחקים עכשיו בגרסה החיה](https://arena-hadacha.vercel.app/)

הסגל כולל את בנימין נתניהו, איתמר בן גביר, טלי גוטליב ונפתלי בנט. המשחק הוא
פארודיה בדיונית ואינו מציג עובדות, ציטוטים או עמדות אמיתיות.

בטלפון המשחק מציע בקר מגע לשחקן 1: חיצים, קפיצה, מכה וכפתור טעינה
שממשיכים לפעול כל עוד מחזיקים אותם. אפשר לעבור בכל רגע בין מגע למקלדת דרך
אייקון השלט בסרגל העליון.

## הפעלה

```sh
npm start
```

פותחים את **http://127.0.0.1:8080**. המשחק משתמש במודולי JavaScript ולכן
יש להפעיל אותו דרך שרת מקומי ולא לפתוח את `index.html` ישירות.

## מצבי משחק

- **מול המחשב:** שחקן 1 בוחר דמות; המשחק בוחר יריב אחר ומפעיל בקר תנועה,
  קפיצה, קליעים וטעינה דטרמיניסטי.
- **קרב מקומי:** שני שחקנים בוחרים דמויות, כולל אפשרות לקרב מראה.
- **בטלפון:** מומלץ לבחור בקר מגע ולשחק מול המחשב; בקר המגע שולט בשחקן 1.

## מקשים

| פעולה | שחקן 1 | שחקן 2 |
|---|---|---|
| תנועה | `A` / `D` | `←` / `→` |
| קפיצה כפולה | `W`, ואז שוב באוויר | `↑`, ואז שוב באוויר |
| התקפה בסיסית | `F` | `K` |
| מכת טעינה | מחזיקים `G` ומשחררים | מחזיקים `L` ומשחררים |

קיצורים כלליים:

- `P` או `Esc`: השהיה והמשך.
- `R`: משחק חוזר.
- `M`: הפעלה או השתקה של צלילים.
- `Enter`: אישור בתפריטים או משחק חוזר ממסך התוצאה.

מכת טעינה מתחזקת עד 1.5 שניות. מכות מעלות את אחוז הנזק; ככל שהאחוז גבוה
יותר, אותה מכה גורמת להדיפה חזקה יותר. רק יציאה מגבולות הזירה קובעת
רינג־אאוט.

## הדמויות

- **נתניהו:** לוח איום מצויר ומכת טעינה קרובה.
- **בן גביר:** אנימציות עמידה וריצה מלאות, מתקפת פיתה ובעיטת תנין מתוך
  גיליון הספרייט שסופק.
- **גוטליב:** קליע “התנגדות!” ופטיש סדר מונפש.
- **בנט:** קריאת “אחים שלי!” ובעיטת טעינה מתוך גיליון הספרייט שסופק.

## פיתוח ובדיקות

```sh
npm test
npm run test:browser
npm run build
```

- בדיקות המנוע מכסות פיזיקה, קפיצה כפולה, התקפות, טעינה, קליעים, רינג־אאוט,
  בחירת ארבע דמויות ובקר המחשב.
- בדיקות הדפדפן מכסות מסך ראשי, שני מצבי המשחק, בחירת דמויות, מובייל,
  HUD, השהיה, תוצאה והרצה מתוך `dist/`.
- `npm run build` יוצר `dist/` ואת `arena-hadacha-poc.zip`.

## מבנה

- `src/engine.js`: פיזיקה, התקפות, נזק, הדיפה ורינג־אאוט.
- `src/ai.js`: בקר היריב הממוחשב.
- `src/renderer.js`: זירת Canvas, דמויות ואפקטי פגיעה.
- `src/game.js`: מסכים, בחירת מצב ודמויות, קלט, HUD, צליל ומסך מלא.
- `tools/process_gotliv_sprites.py`: עיבוד גיליון גוטליב שסופק.
- `tools/process_ben_gvir_sprites.py`: עיבוד גיליון בן גביר שסופק.
- `tools/process_bennett_sprites.py`: עיבוד גיליון בנט שסופק.
- `tools/process_kahane_hand.py`: עיבוד תמונת יד כהנא שסופקה.

המשחק אינו משתמש במיתוג, בשלבים, בצלילים או בנכסים של משחקי זירה מסחריים.
